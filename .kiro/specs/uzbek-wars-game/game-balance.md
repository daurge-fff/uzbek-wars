## Система прогрессии

## Боевая система

### Формула расчета урона

```
Базовый урон = Атака атакующего * (1 - min(0.75, Защита защищающегося / 100))
Случайный разброс = Базовый урон * (0.8 + random(0, 0.4))
Критический урон = Случайный разброс * Множитель крита (2.0 по умолчанию)
Финальный урон = max(1, floor(урон))
```

**Проверки:**
1. Промах: random(0, 100) > Точность атакующего
2. Уклонение: random(0, 100) < Уклонение защищающегося
3. Критический удар: random(0, 100) < Шанс крита

**Примеры расчета:**

Атакующий (уровень 20): Атака 50, Крит 7%, Точность 92%
Защищающийся (уровень 20): Защита 35, Уклонение 3%

```
Базовый урон = 50 * (1 - 0.35) = 32.5
Разброс ±20% = 26 - 39
Средний урон = 32.5
Критический урон = 65
```

### Баланс PvP

**Цель:** Бой между игроками одного уровня должен длиться 8-12 ходов.

```
Средний урон на уровне N = Атака(N) * 0.65 * 1.0 = (10 + N*2) * 0.65
Здоровье на уровне N = 100 + N * 10
Количество ходов = Здоровье / Средний урон

Уровень 20:
Средний урон = 50 * 0.65 = 32.5
Здоровье = 300
Ходов = 300 / 32.5 ≈ 9.2 ✓
```

## Система экипировки

### Генерация характеристик

**Базовые характеристики по уровню:**
```
Атака = 5 + уровень * 2
Защита = 3 + уровень * 1.5
Здоровье = 20 + уровень * 5
Крит шанс = 2 + floor(уровень / 10)
Уклонение = 2 + floor(уровень / 15)
Точность = 5 + floor(уровень / 10)
```

**Множители редкости:**

| Редкость | Множитель | Дополнительные бонусы |
|----------|-----------|----------------------|
| Common | 1.0 | - |
| Uncommon | 1.3 | - |
| Rare | 1.6 | - |
| Epic | 2.0 | +0.2 крит урон |
| Legendary | 2.5 | +0.3 крит урон, уникальный эффект |

**Распределение характеристик по типу:**

| Тип | Основные характеристики | Множитель |
|-----|------------------------|-----------|
| Weapon | Атака, Крит шанс | 1.0 |
| Helmet | Защита, Здоровье | 1.0 |
| Armor | Защита, Здоровье | 1.5 защита, 1.2 здоровье |
| Boots | Уклонение, Здоровье | 1.0 уклонение, 0.8 здоровье |
| Accessory | Атака, Защита, Точность | 0.5 атака/защита, 1.0 точность |

**Пример генерации:**

Редкое оружие уровня 20:
```
Базовая атака = 5 + 20 * 2 = 45
С множителем редкости = 45 * 1.6 = 72
Базовый крит = 2 + floor(20 / 10) = 4
С множителем = 4 * 1.6 = 6.4 ≈ 6%
```
